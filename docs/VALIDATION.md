# 첫줄 검증 기록

## v1.2 · 폴더·파일·보관함 편집

기능 검사: 2026-11-01. 문서·화면 검토 갱신: 2026-11-02 (Asia/Seoul). 프로덕션 빌드를 로컬 preview 서버에서 제공해 검사했다.

- 단위 테스트 **16개 통과**: 기존 12개와 이전 데이터 호환·폴더 삭제·텍스트 가져오기·보관 글 수정 시각 검사 4개.
- Chromium 브라우저 검사 **66개 검증 완료**: 33개 시나리오 × 1280×900 / 360×800. 첫 전체 실행은 63개 통과, 3개 실패였다. 변경된 기능과 맞지 않던 ‘읽기 전용’ 기대값 2개와 모바일 지연 로딩 대기 1개를 수정한 뒤, 영향 범위 20개(새 기능 18개와 기존 보관함 2개)를 재실행해 통과했다. 마지막 실행 기록은 `passed`, 실패 목록은 비어 있다.
- TypeScript 검사와 Vite 프로덕션 빌드 성공. DOCX 추출 모듈은 파일을 불러올 때 로딩한다.
- 홈 카드 ‘작성의 순간’, 메뉴·화면 ‘작성 에디터’ 표시와 ‘다른 글감’의 24개 목록 이동 확인.
- 폴더 생성·문서 이동·색상·소속 복원, 폴더 안 새 문서 생성, 폴더 삭제 후 문서 2개 보존 확인.
- TXT·Markdown·실제 DOCX 구조의 테스트 파일에서 한국어·문단 가져오기 확인. HTML 문자열은 문자로 표시하고 실행하지 않음. 미지원 형식·빈 파일 안내, 파일 읽기 중 편집 보존, 저장 실패 후 재시도 확인.
- 글감 글·연습 문장·원고를 보관함에서 수정하고 새로고침 후 제목·본문·같은 ID 유지 확인. 퇴고 글의 수정본·메모·변화 상태 재계산, 취소·실패 시 기존 내용과 편집 입력 보존 확인.
- 폴더 목록·설정 창·보관 글 편집 창의 Axe WCAG 2 A/AA·2.1 AA 자동 검사 위반 0건. 모바일 가로 넘침 없음.
- 새 화면 캡처: [폴더·문서](images/folders-desktop.png), [모바일 폴더 목록](images/folders-mobile.png), [보관 글 편집](images/archive-edit-desktop.png), [모바일 편집 창](images/archive-edit-mobile.png). README의 소개·변경 비교·SKILL 설명·회고를 초기 문서와 현재 코드에 대조했다.

자동 검사는 실제 사용자 조사나 모든 브라우저의 접근성 보장을 뜻하지 않는다. 운영 주소의 인증 후 조작, 실제 모바일 한글 키보드, Safari/Firefox, PDF·HWP 불러오기는 검증 범위에 포함하지 않았다.

2026-11-01 (Asia/Seoul). 아래 결과는 새 기능을 포함한 프로덕션 빌드로 실행했다.

- 주석 12개 반영: 지정 요소 제거, 제목·설명 변경, 모든 주요 페이지의 날짜 영역 아이콘·작업실 접두어 제거 확인.

- 새 글 보관: 기존 보관 데이터 문자열을 변경하지 않고 두 종류의 글이 함께 검색·표시됨을 확인. 원고 보관 실패와 손상 저장값 보호 확인.

## 화면 시각 점검

에이전트가 Chromium으로 핵심 흐름을 수행하고 저장된 화면을 직접 확인했습니다. 사람 참여자에게 수행시킨 사용성 검증과 구분합니다.

- 데스크톱 홈: 내비게이션, 날짜, 오늘의 글감, 시작 버튼, 직접 제작한 SVG 일러스트, 세 단계 안내와 글감 카드 표시 확인.
- 모바일 홈: 360px에서 제목과 버튼의 겹침을 수정한 뒤 다시 확인. 글감 카드가 2열로 배치되고 조작이 잘리지 않음.
- 모바일 보관 상세: 원문·수정본을 세로로 배치, 줄바꿈 보존, 미션·메모·삭제·새 글 동작 표시 확인.
- 비교 테스트의 HTML 문자열은 보안 검증용 테스트 입력이며 실제 사용자의 글이 아님.

현재 화면: [데스크톱](images/home-desktop.png), [모바일](images/home-mobile.png).

## 검증 중 수정한 문제

- 보관 성공 후 초안을 비우는 과정에서 화면이 홈으로 되돌아가던 경합을 수정. 세 보관 상태·재시도·키보드 흐름으로 재검증.
- React Strict Mode에서 확인창이 닫힌 뒤 초점이 복원되지 않던 문제를 수정. Escape와 원래 삭제 버튼의 초점 대조.
- 작은 안내 문구의 대비와 일부 ARIA 역할 수정. 주요 화면 자동 접근성 검사 재통과.
- 퇴고를 건너뛴 뒤 브라우저 뒤로 이동했을 때 표시되는 수정본과 보관 상태가 다르던 경우 수정.

## 남은 외부 작업 / 검증하지 않은 범위

- **Sites 연동:** 후속 요청으로 Sites를 연결했다. 프로덕션 빌드 대상 재검증과 배포 설정은 [Sites 기록](SITES.md)을 참고한다. 운영 주소의 인증 후 브라우저 조작은 별도 검증 범위다.
- **사용성 검증:** PRD에서 제안한 초보자 3명 내외의 관찰·인터뷰 미수행. 문장력 향상 효과를 주장하지 않음.
- **브라우저 범위:** Chromium 자동 검증 완료. 실제 iOS Safari·Firefox와 실제 모바일 기기 검증은 수행하지 않음.
- 브라우저 저장만 사용하므로 데이터 삭제·도메인 변경·다른 기기 이동 시 글을 이어볼 수 없음. 초기에는 백업·가져오기가 모두 범위 밖이었으며, v1.2에서 문서 본문 불러오기만 추가했다. 전체 데이터 백업 복원은 여전히 제공하지 않는다.
